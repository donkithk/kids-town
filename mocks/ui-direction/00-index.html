在本機打開

  1. 用瀏覽器直接打開 mocks/ui-direction/00-index.html（file:// 可以）。
  2. 或在專案根目錄執行下面指令，再打開連結。
python -m http.server 8765

然後前往 http://127.0.0.1:8765/mocks/ui-direction/00-index.html

概念圖用相對路徑連到 docs/ui-direction/。請從專案根目錄開伺服器。如果只在 mocks/ui-direction/ 裡面開，圖片會找不到。
