# 城鎮風格比較（等角 / 正面）

同一條村嘅兩種畫法，用來揀城鎮地圖風格。**只係設計建議**，未改遊戲、API、經濟數字、測試。

未揀定之前，**唔好**再做放置／移動／升級嘅互動稿。

## 邊兩種

| | 檔案 | 畫法 |
| --- | --- | --- |
| A | `A.html` | 柔和等角。手繪、大約 45°，暖木田園。唔係像素等角，唔係真 3D。 |
| B | `B.html` | 正面立面。屋正面平視，同一種暖木手繪。 |

兩幅內容一樣，先至好比較：

- 舞台 1280×720，Header／Footer 同 #22（城鎮首頁金色選中）
- 圖書館、農場、商店
- 一塊比較明顯嘅空地
- 兩格較淡嘅可建造格
- 擺位意思一樣：後排左圖書館、後排中可建造、後排右農場；前排左空地、前排中商店、前排右可建造
- 建築物係分層 SVG（牆、屋頂、門窗分開），字用 DOM，圖入面冇字

`00-index.html` 會並排（窄螢幕就上下疊）顯示 A 同 B。

## 點樣打開

頁面**冇** `user-scalable=no`，可以放大。

### 電腦

```bash
cd mocks/town-style-compare
python -m http.server 8766
```

- http://127.0.0.1:8766/00-index.html
- http://127.0.0.1:8766/A.html
- http://127.0.0.1:8766/B.html

亦可以直接用瀏覽器打開 HTML。全畫面想唔縮放、自己捲，網址加 `?native=1`。

### 手機

1. 電腦跑上面個 server，手機同一 Wi-Fi，開 `http://<電腦區域 IP>:8766/00-index.html`。
2. 或者分支上 GitHub 之後用 raw.githack：

   `https://raw.githack.com/donkithk/kids-town/cursor/town-style-compare-bc14/mocks/town-style-compare/00-index.html`

3. 建議橫放。可以捏合放大。
