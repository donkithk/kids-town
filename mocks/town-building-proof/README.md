# 城鎮建築證明（柔和等角剪影）

十座種子建築嘅 **Style A** 手繪等角剪影，加一頁靜態互動：空白城鎮 → 揀屋 → 金色格高亮 → 半透明預覽 → 確定放置／取消。取消**唔扣**畫面上嘅金幣同材料。

**只係設計建議。** 未改遊戲、API、經濟數字、測試。未得用戶 Preview 之前 **唔好 merge**。之後先至由 builder 接到產品。

風格來源係 PR #25（`mocks/town-style-compare/`）嘅 A：柔和約 45° 等角、暖木田園、厚線手繪。唔係像素，亦唔係真 3D。

種子順序跟 `backend_v2.py` 嘅 `seed_building_defs()`。註釋寫明：1 圖書館、2 健身室、3 農場、4 商店、5 醫院、6 探險公會、7 工坊、8 燈塔、9 競技場、10 天文台。銀行（id 11）唔喺呢包。

## 點樣打開

頁面**冇** `user-scalable=no`，可以放大。焦點環係 `#c45c26`。可撳目標喺 1280 舞台入面至少 44px。手機想要真實尺寸就加 `?native=1`（舞台唔縮細，自己捲）。

```bash
cd mocks/town-building-proof
```

## 資產清單

剪影係透明 SVG，分層（牆、頂、門窗、物件分開畫），字喺 DOM，圖入面冇字。圖書館、商店沿用 #25 A 嘅等角檔。農場、競技場、燈塔係加咗細節同明顯慢動作嘅樣板（`catalog.html` 有舊版並排）；其餘五座未改。動作寫喺 SVG 入面嘅 CSS keyframes，幅度按地圖格縮細之後仍然睇到。放置頁同剪影紙都有「動畫 開／關」：未撳過就跟系統減少動態（開就預設關動畫）；撳咗就記住，開動畫會蓋過系統設定。關動畫就換靜態剪影。撳格算法冇改。

## 光同地

**光由右上前方打落。** 同 Style A 剪影一致：右牆、右屋頂較光，左牆較暗。陰影跌向左前方。

陰影唔再畫喺每張建築圖入面（以前個橢圓浮喺屋腳下面）。而家每一格用同一張 `assets/shadow-iso.svg`，錨喺嗰格等角足跡中心，向左前移少少，貼住屋底。放置預覽、已起、搬屋都係呢一層；屋影去邊，陰影跟去邊。

地係約 45° 等角菱形磚，同建築格仔用同一個 `(c - r, c + r)` 步距，格仔大小同 tip `3ff954a` 一樣。可建範圍係 **6 欄 × 5 行**（30 格）淺色地塊，橫向填滿地圖；後面一行係升高台階，最前一行係沙徑。地圖可以上下捲，先見到後面大半，捲低見到前面沙徑。確定欄疊喺底，捲到盡前面嗰排會升到欄上面，撳到。金框、紅框、原位都描同一塊菱形。`meadow.svg` 只係天空同遠山。

## 演示點玩

1. 打開係空白等角地磚，未有屋。
2. 左邊揀一座 → 空格變金框「可放」，已有屋嘅格變紅框「唔得」。
3. 點菱形地塊 → 半透明屋影同金框落喺同一格，即使前面座屋嘅圖蓋住後面嗰塊。屋、影、標籤唔接撳。點「確定放置」先扣畫面籌碼。
4. 點「取消」（或者再撳一次同一座、或者 Esc）→ 籌碼唔變，toast：**已取消，資源未扣除**。
5. 點已起嘅屋（地圖或者清單）→ 提起，搬去另一格空格，或者取消。搬屋唔扣資源。
6. 點已佔格：紅框加「唔得」，確定掣停用。點草地空白：紅格「出界」。
7. 「重置地圖」清走示範同還原籌碼。每種建築只起一座。

全部狀態喺瀏覽器入面，冇呼叫 API。
