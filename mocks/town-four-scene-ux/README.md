# 四場景 · 小朋友起屋

城鎮起屋拆成 **四步清楚場景**。四步都玩得通：睇地圖、揀空地、擺位置、升級或打開功能。資源只係呢頁嘅示範籌碼，取消擺位唔會扣。

**只係設計建議。** 未改遊戲、API、經濟、測試。未得用戶 Preview 之前 **唔好 merge**。

風格係 Style A：柔和約 45° 等角、暖木田園。建築剪影 **沿用** `mocks/town-building-proof/assets/` 鎖定檔（`bldg-*-iso.svg`），呢個資料夾 **冇改、冇重畫** 任何建築 SVG。字喺 DOM，圖入面冇字。

同建築證明頁嘅分別：證明頁喺同一版做揀屋、預覽、確定。呢一版用步驟列把四步分開，場景 1 一開始已經有圖書館、農場、商店，場景 4 先至出現升級／打開功能嘅面板。

## 點樣打開

頁面 **冇** `user-scalable=no`，可以放大。焦點環係 `#c45c26`。可撳目標喺 1280 舞台入面至少 44px。手機想要真實尺寸就加 `?native=1`。

剪影係上一層 `town-building-proof/assets/`。Server 要由 **repo 根** 或者 **`mocks/`** 開，先至載到隔籬嘅鎖定檔。只係 `cd` 入呢個資料夾再 `python -m http.server` 會 404 剪影。

### 電腦

```bash
cd mocks
python -m http.server 8768
```

- 互動舞台：http://127.0.0.1:8768/town-four-scene-ux/index.html
- 四步流程圖：http://127.0.0.1:8768/town-four-scene-ux/flow.html
- 全尺寸自己捲：網址加 `?native=1`

由 repo 根開 server 的話，路徑前面加 `mocks/`。

可以直接開某一幕（流程圖用緊）：

- 場景 1：`index.html?scene=1`
- 場景 2（清單打開）：`index.html?scene=2&list=1`
- 場景 3：`index.html?scene=3&pad=1,0&bldg=gym`
- 場景 4：`index.html?scene=4&bldg=library`

### 手機

1. 電腦跑上面個 server，手機同一 Wi-Fi，開 `http://<電腦區域 IP>:8768/town-four-scene-ux/index.html?native=1`。
2. 或者 commit 釘死嘅 raw.githack（見 PR 描述入面嗰條 SHA）。
3. 建議橫放。可以捏合放大。狀態只喺呢頁瀏覽器入面，冇後端。

## 四步

| 步 | 名稱 | 呢個 tip |
| --- | --- | --- |
| 1 | 睇地圖 | 玩得通。已有圖書館、農場、商店。空地唔發光。 |
| 2 | 揀空地／建築清單 | 玩得通。點金框空地，或打開清單揀未起嘅屋。 |
| 3 | 擺位置 | 玩得通。半透明預覽可以搬去其他空地。紅框唔得。取消唔扣。確定先至扣，座屋上面閃一輪金星，然後打開場景 4。 |
| 4 | 升級或打開功能 | 玩得通。升級加等級並扣 💰50 🪵2，同時再閃一輪。打開功能同動作掣有示範結果。 |

種子位置：商店 `(0,2)`、圖書館 `(2,1)`、農場 `(4,0)`。欄行由 0 起計，畫面讀「第 1 欄」係 1。

Header 示範籌碼開始係 💰6000 🪵240 🧱180 🪟12 ⚙️90。取消場景 3 唔扣。確定放置同升級先至扣。
