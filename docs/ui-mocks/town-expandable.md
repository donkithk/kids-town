# 城鎮可擴建外圈（靜態設計稿）

只供預覽。不改遊戲、不接解鎖、也不接建造 API。

畫面是一張 1280×720 的橫向信箱舞台，暖木色，跟登入稿與城鎮四場景同一套外框。打開 `docs/ui-mocks/town-expandable.html`。地塊圖沿用 `mocks/town-building-proof/assets/`，用相對路徑載入。

## 格子怎麼畫

產品可建地圖維持 **8×8**（欄 0..7 × 行 0..7，與 `town-four-scene.js` 的 `COLS`／`ROWS` 相同）。這張稿不把可玩範圍放大。

外圍只加 **一圈** 未解鎖格子。連同中間，畫面外框是 **10×10**（`data-col`／`data-row` 為 −1..8）。鎖住的是 36 格，可建的是 64 格。產品地圖目前沒有既定的外圈尺寸，所以一圈就夠表達「以後會擴大」。沒有第二圈，也沒有更大的可建造格子。

等角步距與地塊沿用城鎮：步距 84×50、地塊 160×158、菱形磚 168×120。整塊菱形會縮小，讓十乘十在舞台裡一次看完，不必捲動才見到鎖。

未解鎖格子可以看見，但不能選來建造。點下去只會出現：「此格尚未解鎖，暫時不能建造。」畫面讀出的欄、行以可建區域左上角為欄 1、行 1；外圍因此會讀成 0 或 9。程式識別仍是 `data-col`／`data-row`。解鎖條件、價錢與接口這次都沒有設計。

圖上的圖書館、商店、農場、燈塔是單格示意，用來對照淺色空地，不代表遊戲裡的佔地，也不能在這張稿移動。

## 怎麼打開

在儲存庫根目錄：

```bash
python -m http.server 8765
```

然後開啟：

`http://127.0.0.1:8765/docs/ui-mocks/town-expandable.html`

不想讓舞台跟著視窗縮小，網址加上 `?native=1`。頁面沒有 `user-scalable=no`，可以放大。
