# 焦點環像素打磨

紅測，預期仍是紅。這份只放像素打磨。粗檢（裁切洞約 6 CSS px、露出來的邊看得到環、尖角開口可以空、不抄測試的 24 站）留在 `WAREHOUSE_PLACEMENT.md`，案例 ID 不重複。

從 `399222f` 原樣搬來的是 `TC-FE-FOCUS-RING-CENTRE`、`TC-FE-FOCUS-RING-SHAPE`、`TC-FE-RING-VERTEX-GAP`、`TC-FE-RING-BAND-WALK`。同一條案例裡又粗又嚴的，粗的 ID 留在倉庫說明，嚴格版加 `-PX`：`TC-FE-PAINT-UNDER-UI-PX`、`TC-FE-FOCUS-RING-NO-FILL-PX`、`TC-FE-MARK-FOLLOWS-SCROLL-PX`。

`c8b39b3` 在 `399222f` 上報告的三條紅都在這裡：`TC-FE-FOCUS-RING-SHAPE` 的 22/24 站、`TC-FE-FOCUS-RING-NO-FILL-PX` 的內緣 2–4px、`TC-FE-RING-BAND-WALK` 的內緣 2.0–4.0 和 1 個裝置像素的洞。不把這些門檻放回粗檢。

## 焦點環對準頂面（TC-FE-FOCUS-RING-CENTRE）

1280×720 與 390×844。`:focus-visible` 菱形環的中心，要和格子頂面菱形的中心相差不超過 1px。頂面中心在地磚外框中心上方 10 個視圖單位（外框寬度除以 168 再乘 10，用畫面上的像素）。

## 焦點環的形狀（TC-FE-FOCUS-RING-SHAPE）

焦點環是格子頂面菱形繞自己的中心均勻放大。四個尖角沿各自的軸在格子尖角外面 2–4px（橫向因為同一比例可以到大約 8px）。每條邊在格子邊外面 2–4px。環的寬高比和格子相差不超過 2%。1280 的 `(3,3)` 大約 150–157 × 89–93。中心仍在 ±1px（`TC-FE-FOCUS-RING-CENTRE` 照舊，不改成鎖舊尺寸）。顏色照舊：內層 `#fff8e7`、外層 `#6b4f2a`，虛線。不鎖線寬。環的內緣大約在格子外 2px，不得壓到選中褐線。選中又聚焦時，重疊只數格子多邊形外面、離邊大約 8px 以內、而且相對未聚焦底圖有變化的環色像素；格子裡面的徽章和地面不算。視窗 1280×720、1100×800、390×844，各量一格邊緣格 `(6,0)` 和一格內部格 `(3,3)`。畫出來的內緣用裝置像素的中心，不是舞台像素，也不是把一整個 CSS 像素取整。24 站只放在沒有被蓋住的那段邊上：排除落在看得見的 `#readyBar`、`#uxPlaceBar`、調色盤活矩形裡面的點（矩形再外擴 1px），也排除奶油帶本身（邊外 2px 和 3px）落進那個矩形的點，並且離開尖角開口再加 3px（開口是邊長的 10%）。24 站裡至少 22 站要打中奶油。奶油只認真正的環色 `#fff8e7` 和貼著它的裝置像素（對 `#fff8e7` 的平方距離 ≤25）。`#fffec5` 離 `#fff8e7` 約 1192，不算奶油。某一邊看得見的長度短於 12px 就跳過那一邊，並寫出長度。內緣最小值 ≥2.0、最大值 ≤4.0。步進 0.1 螢幕 px，連續 3 個奶油樣本才算帶的起點。視窗 1280×720、1100×800、390×844，捲動 0 和 366，`deviceScaleFactor` 1 和 2。確認欄真的把環裁掉時，整條邊擺 24 站會有一邊只剩大約 19–20 站露在外面（390 約 15–16）；站改擺在露出來的那段上之後，老老實實裁掉的環仍要能湊滿 22 站。

## 焦點環不填色，嚴格版（TC-FE-FOCUS-RING-NO-FILL-PX）

焦點環只畫虛線：內層約 3px `#fff8e7`、外層約 2px `#6b4f2a`。環的內緣大約在格子外 2px（2–4px），不得壓到選中褐線，也不填 `#7c2d12`。未選中、只聚焦時，空地、金格、以及邊緣有建築圖的格子（圖書館），中心和每條邊向內至少 8px 的每一點（不排除徽章位置）都要和未選中未聚焦的底圖一致。選中又聚焦時才排除「此格」徽章區域；其餘內部仍要和底圖一致，中心不得是 `#7c2d12`。褐線外緣在格子外 0–1px（用來判斷中線內縮 0.5–1.5px），線寬 2–4px，環整段在褐線外面。環的形狀仍由 `TC-FE-FOCUS-RING-SHAPE` 鎖。像素從截圖差讀。拍底圖之前，全畫面 `#7c2d12` 必須是 0，焦點環層也必須是 0 像素。

## 選中線跟著捲動，環的內緣嚴格版（TC-FE-MARK-FOLLOWS-SCROLL-PX）

1280×720，選中 `(3,3)`。捲動 0 和捲動 366 各量一次。選中線的外緣要在該格當時的活矩形外面 0–1.5px，四邊都是。這條看的是露出來的褐線，不因為確認欄把南尖裁掉就放寬。同一捲動下，焦點環的內緣用和 `TC-FE-FOCUS-RING-SHAPE` 同一個 `ring_device_gaps`：24 站只放在沒被看得見的 `#readyBar`、`#uxPlaceBar`、調色盤蓋住的那段（矩形再外擴 1px，邊外 2px 和 3px 的奶油帶若進了那個矩形，那一站也不放）。至少 22 站要打中 `#fff8e7`（平方距離 ≤25）。看得見的長度短於 12px 就跳過並寫出長度。內緣最小值 ≥2.0、最大值 ≤4.0。裝置像素中心、步進 0.1px。捲動 0 時南尖在確認欄下面，整條邊硬要 20 個奶油樣本會逼產品把環畫進欄裡；站改放在露出來的那段之後，矩形裁切仍然過得了。

## 介面下面的漆，嚴格版（TC-FE-PAINT-UNDER-UI-PX）

基準是清單打開、沒有選中、沒有焦點、同一個捲動。選中 `(0,6)`，以及另外只聚焦 `(0,6)`，清單活矩形裡面的像素差必須是 0。捲動 366、清單打開，再做一次。鍵盤打開銀行面板、而且有一格正聚焦時，面板活矩形裡面的差也是 0。`#readyBar` 和抽屜是 guard：差必須仍是 0。

底尖靠近確認欄的格子另測。1280×720 是 `(3,4)` 和 `(2,5)`。1100×800 和 390×844 用當時的活矩形挑南尖離 `#readyBar` 上緣最近的兩格，並寫明是哪兩格。1100 和 390 跳過已經有建築的格子，在空地裡挑。每次拍底圖之前，全畫面 `#7c2d12` 是 0，環層收起。

兩次像素差的底圖都必須是同一句欄上的句子，而且測試要斷言兩張的句子文字相等。容差仍是平方距離 25，不放寬。文字節點 `Range.getClientRects()` 外擴 1px 以外的像素才比較；字型抗鋸齒留在文字矩形裡。圓角帶不從比較裡拿掉。

聚焦：該格已經選中。同一格失焦一張、聚焦一張，句子都是「已選擇空地…」。兩張裡多出來的 `#fffec5` 或環色會紅。選中線：同一格保持選中並且失焦（環收起）。一張是標記層正在畫，另一張是測試把標記層元素設成 `visibility: hidden`（不改 `display`，測完把原來的 inline visibility 還原）。句子不變，所以換句時圓角上的抗鋸齒不會被算成墨水。標記或環真的畫進欄裡，包含矩形四角、圓角形狀外面的那幾個三角，仍然會紅。

環和選中線用確認欄、調色盤的外框矩形來裁是接受的。那些三角不得有環色、選中線色，也不得有代替色。不要求那裡看得到環，也沒有斷言要求環沿著欄的 `border-radius` 走。站仍然只放在矩形外框沒有蓋住的那段邊上。

確認欄句子（`#readyStatus`、`#placeStatus`）的計算樣式 `text-shadow` 必須是 `none`。產品不得加文字陰影來壓掉字型抗鋸齒。

層疊不用 `elementsFromPoint`。環和選中標記是 `pointer-events: none`，那個 API 會跳過它們。改查四件事：

1. 有效 z。找出焦點環層、選中標記層，和每一個看得見的 `#readyBar`、`#uxPlaceBar`、調色盤，它們最近的共同堆疊上下文（不要把其中一個元素自己當成那個上下文）。環和標記在這個上下文裡的 z（沿著祖先走到該上下文的那一層）必須嚴格小於每一個看得見的欄和調色盤。場景 1、場景 3、建築面板打開、捲動 366、以及改視窗之後都要查。
2. 環若是 canvas：把每個看得見的欄和調色盤客戶端矩形對到 canvas 的裝置像素（用 canvas 矩形和畫布寬高，不是只乘 `devicePixelRatio`），`getImageData` 那個區域，alpha 必須全是 0。
3. 選中標記，以及環若是 SVG：這一版產品沒有把環裁進 `clip-path`。沒有 clip 時，每一個畫出來的 `rect`／`path`／`polygon` 的客戶端外框不得和欄或調色盤相交（0.5px 以內的貼邊不算相交）。若產品改成 `clip-path: url(#…)`，就在欄裡打一格點，用 `isPointInFill`／`isPointInStroke` 看幾何，再看該點是不是落在 clip 裡面；落在裁切後仍看得到的區域裡就是紅。
4. DOM。`.place-bar`、`#readyBar`、`#uxPlaceBar`、調色盤、場景 1 的 `.cta`（`#btnBuild`）子樹裡不得有環或標記的繪製元素：canvas、svg，或 id／class 含 `ring`、`mark`、`focus-lift`。掛在確認欄裡的 `svg.ring-under-bar` 會紅。

場景 1 的「我要起屋」（`.cta`）是蓋住環的實心控制項，和確認欄、調色盤同一份 cover。有效 z 必須嚴格低於它。環的繪製矩形不得留在按鈕裡面（有 clip 時用 `isPointInFill`，沒有 clip 時用客戶端外框）。測試把一格的南尖捲到按鈕的垂直中線再聚焦，按鈕畫出來的外緣裡像素差是 0。不因為按鈕畫在環上面就放行沒裁掉的幾何。

蓋住環的範圍是畫出來的外緣，不是寫死的外擴。每一個看得見的 `#readyBar`、`#uxPlaceBar`、調色盤、場景 1 的 `.cta`：元素的 border box，加上當時 `::before` 伸出 border box 的距離。伸出用計算樣式的 `top`／`right`／`bottom`／`left`（從 padding edge 量，再扣掉元素自己那一邊的 border 和偽元素的 margin）。沒有生成 `::before`，或沒有伸出，就是 0。`.cta` 沒有 `::before` 時，外緣就是 border box。4px 和 48px 都不算進 cover。

環的裁切要貼著這條外緣。`#focusRingClip` 裡對上這塊外緣的洞，每一邊離外緣不得超過 1 個裝置像素。向外超過 1 是死區：調色盤 border box 外 48 螢幕 px 的洞要紅，按鈕外 4px 的洞也要紅。向內超過 1 是裁進畫出來的面上。環的 border box 壓在外緣上、卻沒有對上的洞，算沒裁。裝置像素網格上不足 1 裝置像素的 snap 留下。

確認欄和調色盤的圓角抗鋸齒：同一句、同一格聚焦，一張環層在畫，另一張把 `#focusRingPaint` 設成 `visibility: hidden`（測完還原）。比的是外框再外擴 6px 之後四個角上 22px 見方的裝置像素，扣掉環色 `#fff8e7`、環褐 `#6b4f2a` 和選中褐 `#7c2d12`。剩下的每個通道相差不得超過 2。視窗 1280×720（`deviceScaleFactor` 1）和 1100×800（`deviceScaleFactor` 2），調色盤打開。

## 實線帶要連續（TC-FE-RING-BAND-WALK）

尖角開口不算洞。四個角的開口就是 `TC-FE-RING-VERTEX-GAP` 量的那兩個內端之間的直線距離：設計目標是邊長夠長時 5–8px，測試接受 4–10px。連續裝置像素走查只走每一條邊的兩個實線內端之間，用的就是那條案例寫下來的同一對端點。內端外面、走進尖角開口的那段不查連續，也不把開口算成洞。

內端之間的走查以 1 個裝置像素為一步。沒有奶油的連續樣本不得長過 1 個裝置像素；正好 1 個裝置像素的缺口留下，更長就是洞。每一個打中奶油的樣本，內緣（裝置像素中心，連續 3 個 `#fff8e7` 才起算，半進位到 0.1）都要在 2.0–4.0。只認平方距離 ≤25 的 `#fff8e7`。看得見的 `#readyBar`、`#uxPlaceBar`、調色盤蓋住的樣本跳過，不把矩形裁切算成洞。蓋住的矩形是畫出來的外緣（border box 加當時 `::before` 的伸出），再外擴 1px，連邊外 2px 和 3px 的奶油帶。48px 的調色盤死區不是 cover，落在那裡的樣本不跳過。

這條專門抓住只在 24 個站上補洞或挖洞的畫法：`placeFocusRing` 若按那 24 站把裝置像素標成 blocked，再在奶油帶裡 hold 住不畫，站與站之間的內緣或沿邊的洞仍要紅。

1100×800、`deviceScaleFactor` 2，焦點必須是 Tab 送到 `(3,3)`，不是 `element.focus()`。捲動 0 和 366 都量。那一組每一個樣本的內緣都要在 2.0–4.0，洞不得長過 1 個裝置像素。另外在 `deviceScaleFactor` 1 的 1280×720、1100×800、390×844，以及 `deviceScaleFactor` 2 的 1280×720，同樣捲動 0 和 366。

## 尖角開口是兩條帶的內端（TC-FE-RING-VERTEX-GAP）

四個尖角各量一次。開口是兩條實線奶油帶在這個尖角相會的那兩個內端，之間的直線距離（螢幕 px），不是尖角到帶的距離。每個開口 4–10px。對角相差不超過 2px：北對南、東對西。邊上實線長度除以該邊螢幕長度 ≥0.80，只在邊長 ≥40px 時要求；短邊不鎖這個比例。視窗 1280×720、1100×800、390×844、橫向 844×390，`deviceScaleFactor` 1 和 2。失敗時寫出每個尖角兩個端點的座標。規格上的目標是邊長 ≥40px 時間距 6px、短邊 4.5px（由活菱形的角度算出）；測試只鎖 4–10、相差 ≤2、長邊實線 ≥0.80。拍底圖之前畫面要乾淨。
