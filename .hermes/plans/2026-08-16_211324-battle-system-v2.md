## 1. 屬性系統重設計（5 屬性 + Level 決定 HP）

**決策（用戶確認）**：
- STR 譯名改為 **「臂力」**（= 物理攻擊），合併舊「臂力」(ability_atk)
- HP 純由 Level 決定（同 ATK 脫鈎）
- 唔加 Luk 屬性

**最終 5 屬性：**

| 欄位 | 名稱 | 用途 | 建築來源 |
|------|------|------|---------|
| `ability_str` | 💪 臂力 | 物理攻擊 ATK | 健身室 + 競技場 |
| `ability_int` | 📖 知識 | 魔法攻擊 MATK | 圖書館 + 天文台 |
| `ability_spd` | 💨 速度 | 先手 + 回避率 | 競技場 |
| `ability_crt` | 🎨 創意 | 爆擊率 + 爆擊傷害 | 工坊 |
| `ability_brv` | ⚔️ 勇氣 | 防禦 DEF | 探險公會 |

**移除**：`ability_atk`（合併入 `ability_str`）、舊「體力」概念（HP 改由 Level 決定）。

## 2. 戰鬥公式 v2（草案，係數可微調）

```python
# calc_battle_stats(kid) 重寫
HP   = 20 + level * 8
ATK  = 5 + str * 1.5          # 臂力
MATK = 5 + int * 1.5          # 知識
DEF  = int(brv * 0.6)         # 勇氣
CRT% = min(50, crt * 2)       # 爆擊率
CRTDMG = 1.5 + crt * 0.02     # 爆擊倍率（基礎 150%）
DODGE% = min(40, spd * 1.5)   # 回避率
MP   = 10 + level * 3         # 維持
```

**傷害計算：**
```python
# 普攻
dmg = max(1, ATK - monster.DEF + randint(0, 2))
# 爆擊判定：randint(1,100) <= CRT% → dmg *= CRTDMG
# 蓄力：dmg *= 2

# 技能（物理 scale=str / 魔法 scale=int）
skill_dmg = base + per_lv * bldg_level + (str 或 int) * 1.0
# 爆擊同樣適用

# 怪物反擊
counter = max(0, monster.ATK - DEF + randint(0, 2))

# 先手/回避（新）
if spd > monster.SPD: 先手（該回合怪物唔反擊）
回避判定：randint(1,100) <= DODGE% → 完全回避該次反擊
```

**目標**：技能傷害 ≈ 普攻嘅 1.5–2 倍，令用 MP 有回報。

## 4. 怪物 & Tier 定義

**用戶設定：每一區一日只可打一次**（每日重置，一次/區）。**打贏先計** — 戰敗唔消耗當日次數，可即日重試。

**Tier = 區域編號**（region_id 即 tier）。每區 1 種怪物，tier 越高越強：

```python
# tier t 怪物
HP  = 20 + t * 20
ATK = 4 + t * 3
DEF = t // 2
SPD = t           # 用嚟判斷先手
```

**解鎖門檻**：區域 t 需要玩家 Level >= 解鎖等級（例如 `unlock_level = t * 2`）。

**區域結構**（現有 3 區，可擴展至 10+）：
| tier | 怪物 | HP | ATK | DEF |
|------|------|----|----|----|
| 1 | 野狼 | 40 | 7 | 0 |
| 2 | 白熊 | 60 | 10 | 1 |
| 3 | 巨蠍 | 80 | 13 | 1 |
| 4 | （新）毒蛇 | 100 | 16 | 2 |
| ... | 每 +1 tier 遞增 | | | |

## 5. 掉落系統（權重稀有度 + tier scaling + 保底）

**稀有度分層：**

| 稀有度 | 基礎機率 | 例子 |
|--------|---------|------|
| 普通 common | 70% | 木頭、磚頭、鐵 |
| 稀有 rare | 22% | 皮革、寶石 |
| 珍貴 epic | 7% | 龍鱗、星石 |
| 傳說 legendary | 1% | 限定圖紙/稀有裝備 |

**Tier scaling**（每 +1 tier）：
- `epic` +1.5%
- `legendary` +0.3%

**保底機制（pity）**：
- 每區記錄「連續冇珍貴品次數」，累計 30 次 → 第 31 次保底 epic
- 防黑仔，小朋友唔會打到灰

**每區掉落池**：高 tier 怪物換更好嘅掉落池（巨蠍先跌寶石、Boss 先跌龍鱗）。

## 6. Boss 系統（集料召喚 — 最終方案）

**決策（用戶確認）— 替B 集料召喚，規則如下**：
1. **召喚**：集齊指定材料召喚 Boss（材料 = 該區掉落嘅珍貴品，如寶石/龍鱗）
2. **一週限召喚一次**：成功召喚後進入一週冷卻
3. **打唔贏可再召喚**：戰敗唔消耗冷卻，可即時再召喚（一週內免重付材料）
4. **首殺獎勵**：第一次打贏 → 保底 1 件 legendary ✅
5. **解鎖下一區**：打贏 Boss → 解鎖下一區域 ✅
6. **每週重置**：打贏後一週可再戰（再戰獎勵較細，保底 epic）

**Boss 數值**：`HP ×3`、`ATK ×1.5`、`DEF ×1.5`（相對同 tier 普通怪）。

## 7. 等級 & EXP 曲線（cap 1000）

**決策（用戶確認）**：等級上限 1000，容易升但唔會太快到頂。

```python
# 下一級所需 EXP（線性、平緩）
def exp_for_next_level(level):
    return level * 25
# cap = 1000；總計 EXP = 25 * 1000*999/2 ≈ 12.5M
```

**EXP 獎勵跟 tier scale：**
```python
exp_reward = 15 + tier * 10   # 每場勝仗
```

**每日 EXP（每區一日一次）**：`Σ (15 + 10×tier)`，隨解鎖區域增加。

**里程碑獎勵**：Lv 10/25/50/100/200/.../1000 各派特別獎勵（材料/成就/稱號），令長期有嘢追。

**要 tune 嘅位**：`×25` 係數 + 區域解鎖速度要 playtest 先確認「每日幾多場、幾耐升一級」啱小朋友節奏。
